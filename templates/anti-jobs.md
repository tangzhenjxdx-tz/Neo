# anti-jobs 检查表

anti-jobs 是一串「它绝不会做的事」。没有这一页的 bot，迟早会去干它不该干的事。

## 六个必须回答的问题

1. **它会自己发消息给别人吗？**（发帖、回邮件、评论 PR、@ 人）
   会 → 写清楚只准发给谁，其余一律不准。
2. **它会删东西吗？**（删分支、删文件、清空标签、关闭 issue）
   会 → 改成只出清单，删除由人做。
3. **它会替你做决定吗？**（合并、发布、打 tag、改优先级、报价）
   会 → 改成只起草，你来点。
4. **它会猜吗？**（猜根因、猜意图、猜哪个账号）
   会 → 写明「没有证据就写原因未知」。
5. **没事的时候它会说话吗？**
   会 → 写明「没有值得说的就闭嘴」，并把频率压到最低。
6. **它会向别的 bot 派活吗？**
   会 → 是不是其实该做成团队？不是就删掉。

## 好 anti-job 长什么样

| 空话 | 能执行的 anti-job |
| --- | --- |
| 不要乱操作 | 绝不删除分支，绝不关闭 PR，绝不自动评论 |
| 保持简洁 | 一条消息不超过 5 行，超过就只报最久的前 5 条 |
| 注意安全 | 只读权限；写权限只开 issues: write |
| 别打扰我 | 没有失败、没有恢复的时候一个字都不说 |

## 写完怎么验

把每条 anti-job 念一遍，问：**它违反了，我能不能一眼看出来？**
看不出来，就改成能看出来的写法。
